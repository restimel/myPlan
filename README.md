## Purpose

**myPLAN** is a tool designed to assist judges in **lead sport climbing competitions** with planning and visualizing climbing routes.

It is designed to work seamlessly on both **mobile** and **desktop** devices.

### Features

* Import or take a picture of the climbing wall.
    * Compose several pictures
    * Extends picture

* Add handhold values directly onto the image.
    * Holds can be **added or removed** at any time — values are automatically re-calculated.
    * Holds are **freely movable** after placement.
    * Holds can be **doubled**.
    * Multiple holds can be **linked** to share the same value.

* Export the route as an image to share with the **Jury President** or other judges (e.g., the video judge).

* **Chronometer** — a configurable multi-period countdown timer to time competitors during a route attempt.
    * Define any number of periods with individual names, durations, and end effects (stop, continue, restart, or start next period).
    * Configure sounds, vibration, and intermediate warning beeps per period.
    * Customize background and text colors per period.
    * Save, load, export, import, and share timer configurations as **templates** (via file or QR code).
    * Fullscreen mode with a live clock.
